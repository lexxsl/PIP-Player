PIP-Player Privacy Policy
Updated: 2026-09-13

PIP-Player does not collect or transmit user data to its developer or to an external server. It contains no analytics, advertising, or remote executable code. When the user invokes the extension, locally bundled code inspects available HTML video elements to provide picture-in-picture playback. Videos continue to use their original websites and media sources.

The extension stores only the last picture-in-picture content width and height in chrome.storage.local. These values stay in the current browser profile and are not synchronized by this extension. It does not store browsing history, page URLs, video content, login credentials, or exact window coordinates. Stored dimensions can be removed by clearing extension storage or uninstalling the extension.

The extension requires scripting and HTTP/HTTPS host access to control videos, including embedded frames. This access is used when the user clicks the extension or invokes its shortcut. Original websites and the browser retain their own privacy practices.
